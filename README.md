One original dad joke, written to be told out loud at the dinner table — a
clean pun, a tight setup, and a punchline that arrives right at the end.

## The joke

> My son asked why I keep a pencil behind my ear. I said, 'In case I have to draw the line somewhere.'

100 characters. The pun is "draw the line": the pencil is there so Dad can
literally draw a line — and figuratively, set a boundary.

## How to run

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (Python standard library only).
Deterministic: run it twice and the file is byte-identical.
